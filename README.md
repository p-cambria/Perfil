# Pablo Cambria

**Análisis de datos · Banca y cumplimiento · Ciencia de datos**

Soy un profesional del sector bancario con experiencia en reportes y monitoreo de prevención de lavado de activos y financiamiento del terrorismo (PLAFT). Curso la Maestría en Ciencia de Datos en INTEC y desarrollo proyectos que combinan programación, estadística y comunicación de resultados.

Me interesa aplicar el análisis de datos a problemas de negocio, riesgo y cumplimiento, con atención a la calidad de los datos y a las limitaciones de cada conclusión.
